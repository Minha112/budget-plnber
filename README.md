# Trinity Builders 🏗️

A modern, responsive website for **Trinity Builders**, showcasing construction projects, architectural designs, interior spaces, and landscaping solutions.

## 🌐 Overview

Trinity Builders is a business website designed to present construction services and project portfolios through an elegant and user-friendly interface.

## ✨ Features

* **Modern UI** — Clean and professional website design.
* **Project Gallery** — Showcases residential and construction projects.
* **Interior Design Portfolio** — Displays dining rooms, bedrooms, kitchens, and living spaces.
* **Landscape Portfolio** — Highlights gardens, paving, and outdoor design.
* **Project Showcase** — Features architectural concepts and completed projects.
* **Responsive Design** — Designed to provide a user-friendly browsing experience across screen sizes.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Image assets for project galleries

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Minha112/budget-plnber.git
```

### 2. Open the project

```bash
cd budget-plnber
```

### 3. Run the website

Open `index.html` in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
